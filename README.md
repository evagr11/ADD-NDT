## 📚 ¿Qué es ADD-NDT?

Repositorio de apuntes y prácticas de la asignatura **Acceso a Datos** del ciclo de Desarrollo de Aplicaciones Multiplataforma.

```java
public class AccesoADatos {
    String modulo = "ADD-NDT";
    String ciclo = "DAM - 2º Curso";
    
    String[] contenidos = {
        "Gestión de ficheros y directorios",
        "Flujos de datos (Streams)",
        "XML y DOM/XPath",
        "JDBC y PostgreSQL",
        "ORM con Hibernate",
        "APIs REST con Spring Boot",
        "NoSQL con MongoDB"
    };
    
    public void objetivo() {
        // Dominar la persistencia de datos en todas sus formas
    }
}
```

---

### 🍃 Tema 9.2 — MongoDB y Teorema de CAP  
📍 `ADD-NDT/TEMA9/Apuntes_Tema9.2.md`

#### 🧩 Características de MongoDB
- Almacenamiento en **BSON**  
- Uso de **replica sets**  
- Escalabilidad horizontal  

#### 📚 Terminología
- **Colección** → equivalente a tabla  
- **Documento** → equivalente a fila  

#### 🔺 Teorema de CAP
- **C**: Consistencia  
- **A**: Disponibilidad  
- **P**: Tolerancia a particiones  

MongoDB se clasifica como **CP**.

#### ☁️ MongoDB Atlas
- Servicio en la nube (SaaS) para gestionar clústeres MongoDB.

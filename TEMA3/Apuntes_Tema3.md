## Acceso a datos con DOM y SAX
**DOM** (Document Object Model) **SAX** (Simple Api for XML)

  
## DOM
- **Ventajas**: Al leer el fichero crea un arbol formado por nodos en memoria
- **Desventajas**: Almacena todo el fichero en memoria. Mas lento que SAX

## SAX
- **Ventajas**: Lee el fichero linea a linea, sin cargar todo el documento en memoria
- **Desventajas**: Menos potente que DOM al no conocer todo el documento
  
## Recomendación de uso
**DOM**: Para tareas complejas que requieren conocer todo el fichero y tengamos un objetivo vlaro
